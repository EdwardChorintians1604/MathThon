Materi: Fungsi Turunan

Definisi

Turunan adalah konsep dasar dalam kalkulus yang mengukur laju perubahan fungsi terhadap variabelnya.

Secara matematis, turunan f(x) didefinisikan sebagai:

f'(x) = lim (h→0) [f(x+h) - f(x)] / h

Aturan Dasar

  • Konstanta: Jika f(x) = c, maka f'(x) = 0
  • Pangkat: Jika f(x) = xn, maka f'(x) = n·xn-1
  • Penjumlahan: (u + v)' = u' + v'
  • Perkalian: (uv)' = u'v + uv'

Contoh

Diberikan fungsi: f(x) = 3x2 + 2x + 1

Maka turunannya adalah:

  • Turunan 3x2 = 3(2x) = 6x
  • Turunan 2x = 2
  • Turunan 1 = 0

Hasil: f'(x) = 6x + 2
